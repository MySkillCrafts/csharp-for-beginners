# Code Verification Guide

## Project Structure

- Each lesson should have its own folder
- Folder names should match script names
- Solution and project names should be consistent

## Code Verification Steps

1. **Compare with Script**

   - Check if code matches script description
   - Verify all variables and their values
   - Ensure comments match script explanations

2. **Code Quality**

   - Variables have meaningful names
   - Constants are properly marked
   - Comments are clear and helpful
   - Code is properly formatted

3. **Progression Check**
   - Code builds upon previous lessons
   - No unexplained changes
   - All new concepts are properly introduced

## Coffee Calculator Specific

- Variables should be related to coffee calculation
- Price and tax calculations should be accurate
- User interaction should be clear
- Code should be ready for next lesson's additions

## Common Issues to Check

- [ ] No hardcoded values without explanation
- [ ] No missing comments
- [ ] No unexplained code
- [ ] No inconsistent naming
- [ ] No missing technical information
- [ ] No code that wasn't in the script

## Verification Process

1. Read the script
2. Check the code
3. Compare code before/after
4. Verify all explanations
5. Check for smooth transitions
6. Ensure no missing steps
