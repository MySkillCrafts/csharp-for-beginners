# 🎓 Lesson 1: Arrays vs Lists - When Each Makes Sense

## 📋 Описание урока
Этот урок демонстрирует разницу между массивами (arrays) и списками (lists) в C#. Вы узнаете, когда использовать каждый тип коллекции.

## 🚀 Как запустить

### Вариант 1: Если у вас есть NuGet пакет (рекомендуется для студентов)
```bash
# Установите пакет
dotnet add package CSharpLearning.WebUIHelper

# Запустите проект
dotnet run
```

### Вариант 2: Если у вас есть исходный код WebUIHelper
```bash
# Убедитесь, что WebUIHelper находится в папке ../../WebUIHelper/
# Запустите проект
dotnet run
```

## 🎯 Что вы изучите

1. **Массивы (Arrays)**
   - Фиксированный размер
   - Быстрый доступ к элементам
   - Когда использовать

2. **Списки (Lists)**
   - Динамический размер
   - Гибкость добавления/удаления
   - Когда использовать
