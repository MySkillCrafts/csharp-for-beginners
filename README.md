# C# for Beginners: Step-by-Step

Official code repository for the Udemy course **C# Programming for Absolute Beginners** by [MySkillCrafts](https://github.com/MySkillCrafts).

This repo contains the example projects from the course, organized by section and lesson so you can download the exact code shown in each video.

## What is inside

The course builds real console applications step by step:

| Section | Topic | Main project |
|--------:|-------|--------------|
| 03 | Variables, input, and decisions | Coffee Calculator |
| 04 | Arrays, lists, and dictionaries | Class Roster / Student Grade Tracker |
| 05 | Loops | Daily Planner |
| 06 | Methods | Unit Converter + Daily Planner |
| 07 | More C# data types | TypesDemo |
| 08 | Objects and classes (OOP basics) | Student Management System |
| 09 | Exceptions | Number Guessing Game |
| 10 | Dates, time, and random numbers | Birthday Countdown App |
| 11 | Files and text | Note-Taking App |
| 12 | Debugging | DebuggingDemo |
| 13 | Final project | Flashcard Trainer |

Sections **01–02** (course intro and setup) and **14** (wrap-up) usually do not need downloadable code. **Quizzes** also do not have code folders here.

## Repository structure

Each lesson with downloadable code has its own folder:

```
csharp-for-beginners/
├── Section 03 - C# Basics - Variables Input and Decisions/
│   ├── 01 - Create the Coffee Calculator Project/
│   ├── 02 - Variables Constants and Comments/
│   └── ...
├── Section 04 - Arrays Lists and Dictionaries/
├── Section 05 - Loops - Repeating Work in C#/
├── ...
└── Section 13 - Final Project - Flashcard Trainer/
```

Folder names match the Udemy lesson titles. Inside each lesson folder you will find a Visual Studio solution (`.sln`) or project (`.csproj`) you can open and run.

## How to use this repository

### Option 1: Download one lesson

1. Open the lesson resource link from Udemy.
2. Go to the matching section and lesson folder in this repo.
3. Download the folder or open the project files directly on GitHub.

### Option 2: Clone the whole repository

```bash
git clone https://github.com/MySkillCrafts/csharp-for-beginners.git
```

Then in Visual Studio:

1. Open the `.sln` or `.csproj` file for the lesson you are watching.
2. Press **F5** to build and run the project.
3. Compare the code with what you type along with the course.

## Requirements

- **Windows or macOS**
- **Visual Studio 2022 or newer** (Community edition is free)
- **.NET 9 SDK** (installed with Visual Studio during course setup)

If a project does not run, make sure you completed the setup lessons in Section 02 first.

## If a lesson folder is missing

That usually means the lesson does not need a separate download. For example:

- intro or theory-only lessons
- quizzes
- setup and wrap-up videos

Continue with the next lesson, or keep working in the project from the previous lesson.
